# Chat interactions, 2026-11-07

- The native `OrbitChatWebView` accepts file-URL drops. The coordinator issues short-lived, one-use tokens for these exact user-selected URLs. JavaScript never supplies an arbitrary import path. Drops are accepted over the main or quick chat, excluding the split file editor. Picker and drop use the same importer.
- WebKit's HTML drop fallback streams 512 KB chunks through native upload tokens. Size, byte offsets, expiry and original project are checked before the complete file reaches the same importer. Partial files are aborted and temporary uploads use private permissions. This avoids a multi-GB base64 message when WebKit's internal content view owns the drag.
- Up to eight attachments per message, two GB each, with a 512 MB free-space reserve. Original files are copied into the scoped project's `inputs/chat/` folder. Images become bounded JPEG previews. Video gets three CPU-decoded sample frames and explicit partial-analysis metadata. Audio uses the existing transcription tool. Native PDF extraction is bounded to 64 MB / 160 pages / 200k characters. Office XML extraction is bounded and rejects DTD/entity declarations. Other binary formats are stored as references; no execution or invented interpretation.
- Attachments remain local-only for model inference. Old single-attachment payloads remain supported. Import scope is captured before asynchronous I/O; a project/chat switch cannot attach the result to another chat. Original files remain unchanged.
- Search sits directly above Settings. It searches chat text, projects, agents, rooms, tasks, synchronized email, memory and registered file names. Text-content search is bounded to the latest 1200 registered files of at most 256 KB, under each artifact's own project root. It never scans credentials, model weights or arbitrary external folders. Hungarian accent-insensitive matching treats SQL wildcard characters literally. Results are capped for responsive display.
- Swiping a chat left reveals a separate Delete button; the gesture itself cannot delete. Deletion archives the complete conversation, with a 30-second Undo notice and a persistent Deleted chats list. Active requests/linked jobs block deletion. Files, audit records and task state remain available for restoration. Archived chats are excluded from chat lists, search and normal assistant history. Legacy ungrouped conversations are assigned their own restorable session before archival.
- Close all files either closes clean tabs immediately or offers Save all / Discard / Cancel. Failed saves leave remaining tabs open.
- “készíts egy saját videót egy történettel a youtube shorts projektben” now resolves to the existing Story Studio graph and starts all six wired agents through typed app control. Source URLs, clip editing and scheduled requests keep their own routing.
